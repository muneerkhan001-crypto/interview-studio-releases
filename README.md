# Interview Studio — desktop and Android downloads

Get the apps from the **Releases** section on the right, or from https://aijobs.click/interview/app/#download

- **Windows:** InterviewStudio-Setup-x.y.z.exe
- **Mac:** InterviewStudio-x.y.z.dmg
- **Android:** InterviewStudio-x.y.z.apk

After installing, open the app and pair it with your account at aijobs.click/interview/app/#pair.
The desktop app updates itself when a new version is published here.
